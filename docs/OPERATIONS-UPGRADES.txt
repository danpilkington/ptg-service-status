OPERATIONS AND REPORTING UPGRADES

Deployment: deploy updated src, assets, pages, server.js, database/features.sql, ops/recovery.js and tests. Run node database-setup.js upgrade under the service/database administrator account, then restart the service. This adds the insights storage document for daily security trends. Encrypted recovery format version 4 includes insights; older versions 1-3 remain readable. Runtime data and tenant settings are not overwritten.

Device details: private administrator-only searches and filters, pages of 50 records, and CSV exports of all matching records. Device names, operating systems, compliance and last check-in are shown. DeviceManagementManagedDevices.Read.All is already required by the device overview.
MFA follow-up: administrator-only account names, principal names, registration/capability and registered methods. AuditLog.Read.All is already required by the MFA overview. This Microsoft report excludes disabled users and may lag changes; registration is not proof of MFA enforcement. Details are cached in memory, not in historical storage.

Security trends: successful reports create or replace one daily UTC snapshot per report, retaining 365 days of aggregate counts. The service's existing background refresh requests enabled reports using their five-minute caches. Charts leave gaps for missing days and no history is invented. No device or user identities are persisted in trends. Table displays latest 90 observations. Disabled reports are not collected.

Action dashboard: all incident-review follow-up actions, searchable by owner/title, with open/completed/overdue filters and completion/reopen controls. Overdue compares calendar due dates using Europe/London. Updates are audited and reject stale revisions. The existing detailed review editor remains available.

Maintenance reminders: opt-in checkbox under Dashboard refresh in Overview. Confirmed, unpaused subscribers receive a reminder once within 24 hours, then within 1 hour of published work's start. Work first observed within the final hour gets the one-hour reminder only. Cancelled/rescheduled/started work is checked before dispatch. The durable outbox, unsubscribe links, retry backoff and delivery limits are shared with incident updates. Failed jobs may be accepted more than once after a crash; mail delivery is at-least-once. Reminder keys expire after 14 days. Provider work is included only when its impact is confirmed.

Access diagnostics: Overview shows effective role, granting group Object ID and the timestamp of the successful cached membership check. The server recovery key is identified separately.
Operations overview: published active incidents, upcoming maintenance, open/overdue actions, device compliance gaps and MFA registration gaps. Unavailable reporting is labelled rather than counted as zero.
Draft previews: sandboxed preview of incident/maintenance notices and announcements using the same notice renderer and stylesheet as the public page. Preview remains private and does not publish or send mail. Other staged service and Microsoft assessment details remain in the review-changes list.
