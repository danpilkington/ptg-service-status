Microsoft controls

Use dedicated Entra security groups, including AD Users and Computers security groups synchronised to Entra. Enter the Entra Object ID, not the on-premises objectGUID. Administrator membership takes priority over editor membership. Nested membership is supported. Microsoft sessions recheck membership within one minute; failed checks deny access. Access is managed through the administrator and editor security groups.

Members of the configured groups can sign in automatically. Local accounts and individual Entra ID links are no longer used. Microsoft sign-in requires group access to be enabled.

Requires application permissions User.ReadBasic.All and GroupMember.Read.All for groups, and DeviceManagementManagedDevices.Read.All for devices, with tenant administrator consent. MFA registration requires AuditLog.Read.All application permission and supported tenant reporting licensing. Device reporting also requires Intune licensing.
